# Systematic Problem Solving

## Introduction

Knowing syntax, data structures, and algorithms is only half the battle. The other half is knowing **how to apply them** under the extreme time pressure of a 45-minute technical interview.

Many candidates fail not because they don't know how to code, but because they start coding before they fully understand the problem, leading to a tangled mess of spaghetti code and bugs.

This section covers a repeatable, systematic framework to approach *any* coding problem.

---

## The Framework: UMPIRE

A popular and highly effective framework used in coding bootcamps and FAANG preparation is **UMPIRE**:

1. **U**nderstand the problem.
2. **M**atch to a pattern or data structure.
3. **P**lan the algorithm.
4. **I**mplement the code.
5. **R**eview and Dry Run.
6. **E**valuate complexity.

We will break down each of these steps in the following chapters.

---

## Key Takeaways

- Never jump straight into writing code.
- Problem solving is a structured process, not just a burst of "genius" intuition.
- Following a framework prevents you from freezing when you encounter a problem you've never seen before.
